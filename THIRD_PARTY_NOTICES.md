# Third-party notices

The desktop uses Electron (MIT), ethers (MIT), ws (MIT), ExcelJS (MIT), yauzl (MIT) and their production dependencies. Exact versions, resolved package integrity values and dependency licenses are retained in package-lock.json and bundled dependency package metadata. Electron also distributes Chromium and Node.js notices with the executable runtime.

This is an independent local implementation of the batch-transmitter workflow. It does not embed Maitugou's remote scripts, wallet registration, VIP service, branding assets or network redirect logic.
